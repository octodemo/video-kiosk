Video kiosk settings

Pick the videos and the theme, then launch the kiosk.

Videos

Use a catalog JSON file (see the schema), or a folder. In a folder, each subfolder becomes a kiosk folder. A subfolder name such as GitHub Copilot - Desktop App, CLI, SDK becomes the title and the description.

Theme

The kiosk and this page use the theme that you select.

Kiosk behavior

Return to the start screenAfter this much time with no touch. A playing video is not interrupted.
Attract modeTurn the carousel slowly when nobody uses the kiosk.
Captions on by defaultShow captions when a video has a .vtt file. Viewers can turn them on or off with the CC button in the player.
Caption sizeThe size of the caption text in the player.

The kiosk opens in full screen. Esc exits full screen; the kiosk keeps running and shows a Full screen button.
To come back to this page, press and hold the logo or the title for 3 seconds, or press Ctrl+Alt+S.
